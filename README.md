# Quaternius Dinosaur Kit

Original animated dinosaur assets by [Quaternius](https://quaternius.com/), CC0 1.0 Universal. Source pack: Dinosaur Animated Pack - Dec 2018.

The import workflow downloads only the six original .blend files, exports GLB candidates with Blender 4.2 LTS, and creates a relative-path manifest. Candidate files on main are NOT a release. Inspect every model's orientation and appearance, and visually exercise animation clips on at least two models before approving v1.0.0. Do not use main as a production CDN version.

Once released, resolve each manifest asset's file relative to the pinned manifest URL.
